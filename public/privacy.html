Typer.AI

Privacy, in plain words.

Updated October 16, 2026. This policy covers the Typer.AI extension, its hosted ranking service, and website demo.

Local autocomplete

Local completion reads text in the active supported editor and a nearby heading or page title. The vocabulary stays in memory and resets when you switch editors or reload. The demo doesn't save your notes.

Optional background AI ranking

Cloud ranking is off by default. If you enable it in a cloud-connected build, Typer sends up to 6,000 characters of the active document and up to 300 characters of its title over HTTPS to the Typer server, which forwards them to its AI provider. It doesn't send surrounding web page text. The hosted service runs on Render and uses Google Gemini. Supabase provides the request-budget database.

Our server doesn't store document excerpts or model responses and doesn't log their contents. The hosted Gemini service uses a billing-enabled project. Under Google's paid-service terms, prompts and responses aren't used to improve Google products or train its models. Google may retain and process data for security and abuse prevention under its terms. Self-hosted deployments may alternatively use OpenAI; those requests set store: false, but OpenAI may retain API data under its abuse monitoring and data policies. This is not a claim of zero provider retention.

The website demo uses precomputed Gemini vocabulary for its public examples and never uploads visitor edits.

Limited use

Typer.AI's use and transfer of user information adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements. Document text is used only to provide autocomplete. We don't sell user data, use it for advertising, or use it to train general-purpose AI models. We don't permit people to read document text except where necessary for security, legal compliance, or support you specifically authorize.

What persists

The extension saves your enabled state, confidence setting, cloud consent, and paused sites locally. It doesn't create accounts, writing histories, or user profiles. The server stores request counts, expiry times, and a keyed hash of the requesting IP for rate limiting, using SQLite for local or disk-backed hosting, or Supabase for the hosted service. Expired quota records are removed during subsequent quota operations. Supabase receives quota records only, never your document excerpts or provider keys. Hosting providers process connection information such as IP addresses as part of delivering and securing the service.

Your controls

Turn cloud ranking off at any time, pause Typer on a site, or turn suggestions off. These controls stop future requests and cancel pending extension requests. Removing the extension removes its saved settings. Document vocabulary is held only in memory, so switching editors or reloading clears it.

This release skips password fields and common sensitive input types. If your notes contain confidential information, leave cloud ranking off.
