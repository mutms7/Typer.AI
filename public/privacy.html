Privacy, in plain words.

Local completion reads text in the active supported editor and a nearby heading or page title. The vocabulary stays in memory and resets when you switch editors or reload. The demo doesn’t save your notes.

Optional background AI ranking

Cloud ranking is off by default. If you enable it in a cloud-connected build, Typer sends up to 6,000 characters of the active document and up to 300 characters of its title to the Typer server, which forwards them to the configured provider, Google Gemini or OpenAI. It doesn’t send surrounding web page text.

Our server doesn’t store document excerpts or model responses and doesn’t log their contents. OpenAI requests set store: false, but OpenAI may retain API data under its own abuse monitoring and data policies. Google’s Gemini free tier may use requests to improve its products. The website demo uses precomputed Gemini vocabulary for its public examples and never uploads visitor edits. This is not a claim of zero provider retention.

What persists

The extension saves your enabled state, confidence setting, cloud consent, and paused sites locally. The server stores request counts and a keyed hash of the requesting IP for rate limiting, using SQLite for local or disk-backed hosting, or Supabase for free hosting. Hourly records expire after their limit window. Supabase receives quota records only, never your document excerpts or provider keys. It doesn’t create accounts, writing histories, or user profiles.

Your controls

Turn cloud ranking off at any time, pause Typer on a site, or turn suggestions off. These controls stop future requests and cancel pending extension requests. Removing the extension removes its saved settings.

This release skips password fields and common sensitive input types. If your notes contain confidential information, leave cloud ranking off.
